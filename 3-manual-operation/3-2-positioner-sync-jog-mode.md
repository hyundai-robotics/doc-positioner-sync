# 3.2 位置器同步 jog 模式

位置器同步 jog 模式仅在完成位置器校准后可用。
在位置器独立 jog 模式下，按下教学挂件上的“crd.sys”按钮将显示“Synchronized S1”。在此模式下，当位置器移动时，机器人会跟随位置器的运动并执行同步 jogging。
