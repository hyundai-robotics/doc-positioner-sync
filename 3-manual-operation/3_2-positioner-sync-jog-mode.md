# 3.2 定位器同步移动模式

定位器同步移动模式仅在完成定位器校准后可用。
在定位器独立移动模式下，按下教学 pendant 上的 "crd.sys" 按钮将显示 "Synchronized S1"。在此模式下，当定位器移动时，机器人跟随定位器的移动并执行同步移动。
