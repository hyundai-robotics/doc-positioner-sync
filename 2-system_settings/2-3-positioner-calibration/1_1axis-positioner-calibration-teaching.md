# 2.3.1 教学 1-Axis 位置器校准程序

1. 选择要教学的程序。

2. 对于 1-Axis 位置器，在位置器上固定一个尖端教学点。将这个教学点尽可能远离旋转中心以提高校准准确性是很重要的。

3. 将位置器在一个方向上旋转约 30°，并精确地教学三个点以记录程序。教学方法如下面的图所示。
  对于线性位置器，使用相同的方法教学两个尽可能远的点。

4. 教学时，尽量保持机器人的姿态一致。
